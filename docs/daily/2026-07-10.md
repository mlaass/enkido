## cedar/

- **feat(vm): crossfade per-bus stems across a hot-swap** (`0d05e5eb`)  
  Extended the equal-power crossfade that the master has always received to cover per-bus stems when a program is hot-swapped. The outgoing program's per-bus buffers are snapshotted immediately after it runs; the incoming program's matching buses are blended at equal-power. Buses only the new program has fade up from silence; orphaned buses vanish. Implemented via a 64 KB preallocated scratch pair; programs without buses are unaffected. Zero-alloc trap confirmed green.  
  _Files touched: 5_ (`crossfade_state.hpp`, `vm.hpp`, `vm.cpp`, `codegen.cpp`, `test_bus_routing.cpp`)

- **fix: reconcile qodo review findings — BUS_TRIM statefulness** (`e12a7e1`)  
  Added `BUS_TRIM` to the `opcode_is_stateful()` explicit list so disassembly and state-ID tooling correctly reports the `SlewState` it owns.  
  _Files touched: 1 in cedar_ (`generated/opcode_metadata.hpp`)

## akkado/

- **feat(bus): optional friendly bus label on bus()/mixer()/master()** (`857a952`)  
  A trailing string argument now attaches a human-readable label to the bus (`bus(1, sig, "kick")`), surfaced on `BusBufferMapping::label`. Hosts use it to name stem files and mixer strips directly from the code ("the code is the DAW", studio daw-core OQ4). Backward-compatible: a string is only consumed as a label when a signal/closure argument is still present.  
  _Files touched: 4_ (`builtins.hpp`, `codegen.hpp`, `codegen.cpp`, `test_bus_routing.cpp`)

- **feat(vm): bus crossfade — codegen side** (part of `0d05e5eb`)  
  Codegen emits the bus index into `inst.rate` for `BUS_TRIM` (a compile-time count field, not a runtime-tunable param), allowing the VM to recover the bus→buffer map during a swap.

## tools/

- **feat(nkido): render --stems and --float32** (`e0351ce`)  
  `nkido render --stems` writes one WAV per non-master bus alongside the master, tapped from the bus scratch pair post-`process_block` and named from the bus label when available (`<out>.kick.wav`, else `<out>.bus<N>.wav`). `--float32` outputs 32-bit IEEE float WAV for sample-exact comparison against the studio's float path. Doubles as the render-equivalence harness (OQ10). Defaults unchanged (16-bit PCM master only).  
  _Files touched: 2_ (`bytecode_loader.hpp`, `main.cpp` +101 lines)

- **fix: stem collision on duplicate bus labels** (`e12a7e1`)  
  Two buses sharing a label (or sanitizing to the same filename) previously overwrote each other's WAV. Now suffix the bus index on collision.  
  _Files touched: 1 in tools_ (`main.cpp`)
