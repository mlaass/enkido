## akkado/ — 10 files touched

### feat(akkado): overload resolution Phase 4 — user-function overloading (`ceaedbd`)
Multiple `fn name(...)` definitions with distinct parameter signatures now coexist in the
symbol table; the call site selects one by argument type (first-match, declaration order).

- `Symbol::user_function` (single slot) replaced by `Symbol::overloads` (vector); `primary_overload()` is the fallback target. New `DefineFunctionResult` enum signals Added / Accumulated / ReplacedSameSignature.
- `UserFunctionInfo::is_stdlib` tags prelude-origin defs so user code can shadow the stdlib base layer for a given name.
- Codegen: size==1 keeps the unchanged direct path; size≥2 builds one `DispatchPattern` per overload, classifies args by visiting (cached, no double-emit), and calls `resolve()`. Unresolvable/ambiguous calls emit W170 and fall through to the first overload.
- `ArgDescriptor::polyphonic_scalar_incompatible` mirrors the binding's polyphonic-pattern scalar rejection so a polyphonic pattern always routes to a `: Pattern` overload.
- `shared_block_key()` appends a signature suffix only for overloaded names — per-overload BLOCK_CALL bodies, zero regression for single-def bytecode.
- Analyzer, `const_eval`, and `codegen_arrays` updated for multi-body recursion, overload-aware arity checks, and fn-as-value first-overload selection.
- **Tests:** +11 `[overload]` codegen cases, +2 `[symbol_table]` cases. Suite: 321,514 assertions / 1,187 cases green.

### feat(akkado): overload resolution Phase 3 — multi-form builtin migration (`8ce5e61`)
Migrates multi-form builtin families to the declarative overload model via `lookup_builtin_overloads`.

- `pan` / `pingpong` / `smooch` / `wt` / `wavetable`: registered as single `LegacyHandler` patterns; removed from `special_handlers` map.
- `delay` / `delay_ms` / `delay_smp`: single `Builtin` patterns; redundant func-name rate ladder retired.
- `sample` / `sample_loop`: two `Builtin` patterns keyed by id-slot type (String name form, then Signal numeric/runtime id). Codegen calls `resolve()` and rejects non-String/Signal ids with new diagnostic E424.
- **Tests:** +9 `[overload]` cases (table shape, resolve-by-id-type, E424). 321,470 assertions / 1,176 cases green, no existing tests modified.

### test(windows): fix use-after-free in `find_instruction` call sites (`345371a`)
`find_instruction(get_instructions(result), op)` returned a pointer into a temporary `std::vector`
destroyed at the end of the full expression. GCC left the freed memory readable; MSVC's debug
allocator stomped it, causing 21 `[stereo-native]` test failures on Windows.

- Deleted the rvalue overload of `find_instruction` so future regressions are compile-time errors.
- Rewrote 36 call sites in `akkado/tests/test_types.cpp` to the safe two-step pattern.
- Windows result: 70/70 `[stereo-native]` cases pass (was 21 failures).
