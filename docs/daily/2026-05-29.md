## Overview

A very dense day dominated by a single multi-step architectural refactor: moving `akkado_compile` off the AudioWorklet thread into a dedicated Web Worker. The work progressed from PRD → WASM surface → worker boot → result extraction → worklet rewire → main-thread routing → fix → testing, landing as v0.4.3. Alongside that: a growable `BufferPool` (lifting the hard 256-buffer cap), an `_` placeholder fix in specialized call handlers, and an extensive hot-swap regression test suite.

## cedar/

**Files touched**: ~10 | **Key commits**: 1

- **feat(cedar+akkado): growable BufferPool + sum/mean codegen accumulator** (`d4c6ce2`)  
  Lifts the hard 256-buffer cap that blocked patches fanning wider than ~5 chord notes × ~8 unison voices (E101 "Buffer pool exhausted"). `BufferPool` is now a chunked slab list — up to 64 lazily-allocated 256-buffer slabs (16 384 total by default). Slab pointers are stable across growth so audio-thread reads survive a compile-thread hot-swap. `vm::load_program` scans bytecode for the highest referenced buffer index and calls `pool.ensure_capacity()` before publishing. Also: `BufferAllocator` gets a LIFO free-list, and sum/mean codegen rewrites per-voice ADD chains as a single accumulator + N−1 in-place ADDs (~14 buffers saved per 8-voice cluster).

## akkado/

**Files touched**: ~20 | **Key commits**: 10

- **feat(akkado): `_` placeholder in specialized call handlers** (`0a0815e`)  
  `poly(@, instr, _, 2.5)` previously rejected `_` with E402 in specialized handlers (`poly`, `tap_delay`, `bus`, `mixer`). New `codegen::resolve_underscore_defaults` rewrites each `_` at an optional slot with a numeric default into a synthetic `NumberLit`. Also fixes `poly/mono/legato` `BuiltinInfo` `defaults[]` arrays, which were indexed by absolute param position (NaN-padding for required slots) instead of the optional-slot-indexed convention used everywhere else.

- **feat(wasm): buffer-based state-init exports** (`9de8b3c`)  
  Header-only codec in `akkado/include/akkado/state_init_buffer.hpp`. New WASM exports — `cedar_apply_state_inits_from_buffer`, `akkado_resolve_sample_ids_from_buffer`, etc. — take packed self-describing buffers instead of reading `g_compile_result`, enabling a future caller from a separate WASM instance to drive them. Pinned by a Catch2 round-trip test.

- **test(akkado): hot-swap regression suite** (`e0c62bf`, `b42003f`, `3f545f6`, `a59b199`, `0e56050`)  
  Five test additions across `test_hot_swap_determinism.cpp` and a new `test_hot_swap_event_transforms.cpp`:
  - Per-event voice-fire counter (catches "3-of-4 unison voices go silent" regressions)
  - Broader regression for nested `unison`/`poly` + ADSR + reverb patches
  - Chain (5 consecutive edits) + rapid-fire (20 micro-edits) stress cases
  - Canonical reference test with Goertzel spectral energy + Pearson correlation
  - Bit-equality test that mirrors the WASM `apply_state_inits` path for all `StateInitData::Type` variants

- **revert(akkado): restore `osc("sin", …)` in snapshot fixtures** (`a599764`)  
  Migrating fixture sources to the new dedicated builtins silently shifted FNV-1a semantic-ID hashes, breaking bytecode snapshot tests. Seven fixtures reverted to the legacy `osc()` form.

- **test(akkado): scales dispatcher no longer compile-fails on non-literal scrutinee** (`a08da95`)  
  With the growable `BufferPool` from `d4c6ce2`, match-based dispatchers now compile for runtime-valued scrutinees (fits without hitting the old 256-buffer cap). Assertion inverted to verify `required_buffers > 256`.

## web/

**Files touched**: ~20 | **Key commits**: 13

The headline change is the compile-off-audio-thread refactor, implemented in 7 incremental steps:

1. **feat(web): spawn compile worker alongside the worklet** (`b66b04f`) — Bootstraps a dedicated `Web Worker` owning its own `nkido.wasm` instance; accepts `{type:'compile', gen, source}`, replies with bytecode + diagnostics.

2. **feat(web): full compile-result extraction in the worker** (`3a8a924`) — Extends the worker to produce all four wire-format buffers (bytecode, `stateInitsBuf`, `midiSourcesBuf`, `blockTable`), metadata (samples, SF2, MIDI, params, viz), and disassembly JSON. C++ packers in `nkido_wasm.cpp` expose ptr+size accessors.

3. **refactor(worklet): consume packed buffers via `loadProgram`** (`1df0fc2`) — Rips `compile` and `loadCompiledProgram` message handlers out of the AudioWorklet. The worklet now only speaks `loadProgram` with the new packed shape. Drops legacy WASM exports; `SlotBusy` retry simplifies to a single per-`process_block` re-run.

4. **feat(web): route compile through the worker; supersede-by-newest** (`2f27787`) — Main thread routes every `evaluate()` through the worker. Monotonic `gen` field lets stale results be dropped (rapid Ctrl+Enter collapses to latest). Per-gen resolvers in `pendingCompileResolves: Map<gen, resolve>`.

5. **fix(web): force-fresh heap view in compile worker `copyBytes`** (`c93ea81`) — Emscripten's module-cached `HEAPU8` view becomes stale after any WASM call that grows linear memory (`std::vector::resize` inside C++ packers). Switches `copyBytes` to source a fresh `Uint8Array` view from `wasmMemory.buffer` first.

6. **test(e2e): compile worker recovery** (`c319bb1`) — Adds `audioEngine.terminateCompileWorker()` test hook and an e2e spec exercising worker-crash recovery: terminate mid-session, compile again — store surfaces a synthetic diagnostic and respawns.

7. **docs: worklet thread contract** (`48884c1`) — Spells out the thread contract in `CLAUDE.md`: exact set of exports the worklet may call, pointer to the compile worker for everything CPU-heavy.

Other web changes:

- **fix(deploy): apply `netlify.toml` on deploy + ship static SPA fallback** (`fe5d48b`) — `nwtgck/actions-netlify` was never receiving `netlify-config-path`, so the SPA redirect + COOP/COEP headers + immutable caching in `netlify.toml` were ignored. Adds `_redirects` and `_headers` to `web/static/` as a belt-and-suspenders fallback.

- **test(e2e): Playwright hot-swap audio-continuity test** (`2ac46422`) — `window.__nkidoTest` surface with `readRms()` / `captureRmsTrace()`. Spec captures per-20 ms RMS while firing 6 identical-source recompiles and asserts no contiguous silent run.

- **test(e2e): tighten hot-swap test** (`ca5e3dc`) — Root-causes audible gap to `akkado_compile` running on the AudioWorklet thread. 20 rapid recompiles 250 ms apart (up from 6 × 400 ms) to make the flaky failure deterministic.

- **test(e2e): temporarily skip unison-pad hot-swap test for v0.4.2** (`4f39a6d`) — Skipped (not threshold-relaxed) to allow v0.4.2 to ship while the compile-off-thread work lands.

- **chore(patches): refresh `index.json` + pre-commit hook for welcome patches** (`a428590`) — `index.json` descriptions updated to match actual patches; adds `scripts/hooks/pre-commit` that regenerates `welcome-patches.generated.ts` whenever a commit touches `web/static/patches/welcome/`.

- **docs(akkado): migrate `osc("waveform", X)` to dedicated builtins** (`ce1e180`) — Bulk rewrite across 167 files (docs, PRDs, tutorials, embedded source strings in C++ tests, patch files) from legacy `osc()` form to `sine`, `saw`, `tri`, `sqr`, `noise`, `phasor`.
