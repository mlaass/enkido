## cedar/ — 4 commits, 7 files touched

**Live-recompile click fix — three-part series:**

- **fix(cedar): snapshot state pool across crossfade dual-execution** (`13de7366`)  
  `perform_crossfade()` was running old and new programs against the shared `state_pool_` in a single block, advancing oscillator phase/time by 2× real time. Added `StatePool::copy_states_from()` and a `shadow_state_pool_` pre-allocated in the VM; the crossfade now does snapshot → run old → restore → run new → mix. Reduced [recompile] failures from 5/9 to 1/9.

- **fix(cedar): deep-copy audio arena buffers in crossfade snapshot** (`93ed024e`)  
  The state-pool fix left DSP buffer *contents* (delay lines, reverb tank, etc.) shared between the two dual-execution passes. Added `AudioArena::copy_used_from()` (bulk memcpy of the bump-allocator's used region) and `shadow_audio_arena_` in the VM. Crossfade now snapshots and restores both state pool and audio arena.

- **fix(cedar): skip crossfade on byte-identical recompile** (`0e832390`)  
  Equal-power mix `cos+sin` peaks at √2 ≈ 1.414 at mid-crossfade when both inputs are identical, producing gain jumps at block boundaries. Added `content_hash` (FNV-1a over instruction bytes) to `ProgramSignature`; `requires_crossfade()` returns false when hashes match. [recompile] suite now 9/9 passing.

- **feat(effects): delays.hpp dry/wet cleanup** (`b31d3f3e`, partial)  
  `delays.hpp` inner loops now call `cedar::drywet::mix()` instead of the inline `x*dry + delayed*wet` expression, bringing the delay family in line with all other effect opcodes.

## akkado/ — 4 commits, 10 files touched

- **fix(codegen): mini-notation patterns fit one cycle per Strudel convention** (`5c1c0cab`)  
  Codegen was assigning one beat per top-level element (`"c d e f g a b c5"` → 8 beats / 2 cycles). Fixed all primary, transform-base, and synthetic-pattern (`run`/`binary`/`binaryN`) sites in `codegen_patterns.cpp` to use `cycle_length = 4.0f` beats. Added an 8-case end-to-end regression suite (`test_codegen_cycle_timing.cpp`). **Breaking change:** patterns without exactly 4 top-level elements will sound different; migrate via `.slow(N/4.0)`.

- **fix(analyzer): preserve Pattern symbol-kind through transform-on-binding** (`2fbb2305`)  
  `notes = n"…".slow(2)` caused downstream `notes |> saw(@freq)` to fail E061 because `collect_definitions` had no `MethodCall` case on the assignment RHS. Added `is_pattern_producing_expr()` walking `MethodCall→receiver` and `Call→callee-name`. New `MethodCall` + extended `Call` branches register matching bindings as `SymbolKind::Pattern`. `codegen_patterns.cpp` delegates non-MiniLiteral pattern nodes to `visit()`. Regression tests cover every §10.2 variant from the audit doc. Patches `soundfont-play.akk` and `visualizations.akk` reverted to the natural `notes = n"…".slow(N)` form.

- **test(fuzz): rapid-recompile audio fuzz + artifact metrics** (`57283316`)  
  New `akkado/tests/fuzz/artifact_metrics.hpp` (click detector, sanity scanner, beat monotonicity, edge counter, block-energy trace) and `test_fuzz_recompile_audio.cpp` with 8 Catch2 cases under `[fuzz][recompile]`. Covers continuity vs no-swap baseline, pulse-count parity, beat monotonicity, long-tail energy, random-program stress, and regression corpus.

- **feat(effects): surface dry/wet params in editor** (`b31d3f3e`, partial)  
  `serialize_builtins_json()` now appends `extended_param_names` with `required: false, extended: true` after positional params, so dry/wet wired via `ExtendedParams` show up in signature-help and autocomplete. `BuiltinParam` TS type gains optional `extended?: boolean`.
