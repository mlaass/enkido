# Daily Summary 2026-05-21

**15 commits** | **1 contributor**: Moritz Laass

The day completed the entire control-flow infrastructure roadmap (L1–L3 of
`prd-runtime-functions-control-flow`) in one sweep: `when()`, `loop()`,
`#inline`/recursion-rejection, BLOCK_CALL/BLOCK_BIND, FOREACH_EVENT +
subprogram table, and `each()`/`reduce()` all shipped. A new single-voice
`sf_voice` soundfont opcode was added. Seven PRD documents were updated to
reflect shipped work and resolved design questions.

## cedar/

**15 files touched**

- **feat: FOREACH_EVENT + subprogram table + POLY migration (L3)**
  (`ad6aed6`) — New opcode 215; `ProgramSlot` gains a `BlockEntry` table;
  `poly()`/`mono()`/`legato()` migrated to uniform FOREACH_EVENT dispatch
  (bit-exact); PER_ITERATION and SHARED allocators added
  (`ForeachIterState`/`ForeachSharedState`); `VM::set_block_table` staged for
  next load.

- **feat: BLOCK_CALL shared-block fn dispatch (L2)** (`21f73ef`) —
  `execute_block_call` copies caller arg buffers into the body's convention
  param bank under XOR-composed state-id isolation; `BlockEntry` extended
  with `param_base` + `body_output`; RET reserved as no-op.

- **feat: BLOCK_BIND — shareable fns with >5 params (§4.2)** (`9690a6a`) —
  Opcode 216; dispatch-loop scans a contiguous BLOCK_BIND run and copies
  extra param slots into the body bank; `MAX_SHARED_FN_PARAMS = 32`.

- **feat: each()/reduce() VM support (L3)** (`5b7746b`) —
  `run_foreach_per_iteration` fills a 7-buffer event-record bank
  (vel/dur/note/chance/time/gate/trig) with synthesized per-sample gate/trig;
  `run_foreach_shared` re-seeds the accumulator per block.

- **feat: LOOP_STATIC opcode (L1 Part B)** (`9776ded`) — Header marker in VM
  dispatch loop; `rate` = body length, `out_buffer` = iteration count; VM
  re-runs the next `body_len` instructions `count` times with shared state.

- **feat: SKIP_IF_ZERO/SKIP_IF_NONZERO — block-rate conditional (L1 Part A)**
  (`41bb96c`) — Dispatch-loop control opcodes (not `execute()` switch);
  predicate sampled at sample [0]; forward-only; ~79% CPU reduction when
  expensive branch is skipped.

- **feat: SF_VOICE single-voice soundfont opcode** (`c374b3c`) — Opcode 66;
  `op_sf_voice` factored from SOUNDFONT_VOICE's per-voice loop;
  `SFVoiceState` with up to 8 arena-allocated sub-zones; pan-only stereo
  output (true SF2 stereo-pair linkage deferred).

## akkado/

**26 files touched**

- **fix: fn arrow body no longer swallows the next line** (`7a31d9d`) —
  `parse_identifier_or_call` now extends an identifier into a call only when
  `(` sits on the same source line; fixes false E240 recursion rejections in
  multi-param fn bodies.

- **feat: BLOCK_CALL codegen** (`21f73ef`) — Speculative-compile-with-rollback
  eligibility check; `count_fn_calls` pre-pass; `get_or_compile_shared_block`;
  `emit_block_call`; per-call-site state isolation via `block:<fn>@callsite_N`
  path hash. Fixed `emit_stream()` to stop free-emit helpers from leaking
  shared-fn-body instructions into the main stream (~102 call sites rerouted).

- **feat: BLOCK_BIND codegen** (`9690a6a`) — Param cap lifted to 32; params
  5..N-1 emitted as BLOCK_BIND opcodes before the BLOCK_CALL; fns beyond 32
  fall back to per-site inlining.

- **feat: each()/reduce() surface + event-record lambda params (L3)**
  (`5b7746b`) — Dual-bound event-record lambda parameter
  (`n.freq`/`n.vel`/`n.gate`/… resolve to convention slots); `each()` is a
  PER_ITERATION side-effecting sink; `reduce()` is a SHARED accumulator,
  polymorphic with the compile-time array `reduce()`.

- **feat: FOREACH_EVENT codegen + each_voice() surface** (`ad6aed6`) —
  `CodeGenResult` carries subprogram bodies + block table; `emit()` redirects
  into open block via a subprogram stack; `handle_poly_call` emits
  `FOREACH_EVENT(VOICE_POOL)`; `each_voice(input, lambda)` lowers to
  `FOREACH_EVENT(PER_ITERATION)`; legacy `POLY_BEGIN/POLY_END` path retained
  behind `CompilerOptions::legacy_poly`.

- **feat: #inline annotation + recursion rejection (L2)** (`16b166c`) — New
  `#` lexer token; statement-position `#inline` attaches to `fn` declarations;
  call-graph pass rejects recursive fns (E240 direct/mutual, E244 inline cycle,
  E246 misplaced annotation, E249 unknown annotation).

- **feat: loop(){} bounded static iteration (L1 Part B)** (`9776ded`) —
  Contextual keyword (only `loop(N) { … }` shape); body's `@` is the running
  accumulator seeded by the pipe LHS; count must constant-fold to a
  non-negative integer (E243); channel-count mismatch (E252); body >255
  instructions (E253).

- **feat: when() block-rate conditional (L1 Part A)** (`41bb96c`) —
  `handle_when_call` lowers to `SKIP_IF_*`; only the taken branch's opcodes
  run; distinct semantic-path components keep branch state IDs separate;
  E247 branch channel-count mismatch, E248 >255-instruction branch.

- **feat: sf_voice builtin + $soundfont_alias directive** (`c374b3c`) —
  `handle_sf_voice_call` resolves file/preset literals at compile time and
  emits one stereo `SF_VOICE`; E520–E522 for missing/invalid arguments.
