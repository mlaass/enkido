## Two major features landed: Spread syntax + Records system unification

### Spread syntax — Phases 1–7 (akkado/)

A full `..expr` spread operator for call arguments and array literals, shipped in seven incremental phases.

- **Phase 1** — Parser: `spread_source` field on `ArgumentData`; `parse_argument()` detects `..expr` prefix; `parse_array()` wraps spread elements in `Argument` nodes. (`ast.hpp`, `parser.cpp`, +266 lines)
- **Phase 2** — Analyzer: `has_spread_arg()` helper; calls containing any spread arg skip arg-count/reorder/shape checks until codegen materialises the real list. (`analyzer.hpp`, `analyzer.cpp`, +120 lines)
- **Phase 3** — Codegen: `ExpandedArg` struct and `expand_call_arguments()` helper; expands `..record` (named fill) and `..array` (positional fill), emits E140 for non-record/array sources, E180 for mixed spread types. (`codegen.hpp`, `codegen.cpp`, +121 lines)
- **Phase 4** — Wired into user-fn and `FunctionValue` calls: `expand_call_arguments` routes spread args; positional-first then by-name binding; E105/E107/W160 diagnostics. Also fixes `clone_subtree`/`substitute_nodes` to remap `ArgumentData.spread_source` (prevented infinite recursion on pipe-rewritten ASTs). (`analyzer.cpp`, `codegen_functions.cpp`, +491 lines)
- **Phase 5** — Array literal spread: `[..a, b, ..c]` flattens correctly; E140 if source is not an array; single-element array-spread always wraps as Array. (`codegen.cpp`, +109 lines)
- **Phase 6** — Builtin spread via synthetic `PreResolved` nodes: `NodeType::PreResolved` codegen-only node; spread args materialised as a synthetic `Argument` chain spliced in place (RAII restores canonical AST). All special-handler builtins (`lp`, `hp`, `samples`, etc.) now accept `..record`/`..array` transparently. (`ast.hpp`, `codegen.hpp`, `codegen.cpp`, +147 lines)
- **Phase 7** — Integration tests: multiple record spreads (later wins), nested array spread, closure calls with spread, empty spread fallthrough, spread + override. (`test_codegen.cpp`, +70 lines)

**Files touched (akkado/):** `ast.hpp`, `parser.cpp`, `analyzer.hpp`, `analyzer.cpp`, `codegen.hpp`, `codegen.cpp`, `codegen_functions.cpp`, `test_parser.cpp`, `test_analyzer.cpp`, `test_codegen.cpp` — ~10 files, ~1350+ lines added
