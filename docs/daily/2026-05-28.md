## cedar/

**Files touched: 8**

- **fix: touch foreach_event state so hot-swap GC keeps it** (`1fd6c95`)
  `VM::execute_foreach_event` used `get_if` (no touch side-effect) to select among PolyAllocState / ForeachIterState / ForeachSharedState. After a crossfade the GC swept those untouched slots, causing the voice pool to vanish and producing a ~0.9 DC drone until page reload. Fix: explicit `state_pool_.touch(inst.state_id)` after each successful `get_if` branch.

- **fix: heap-allocate StatePool tables to fit VM on default stack** (`1c5483b`)
  StatePool's three fixed-size tables (MAX_STATES=4096) totalled ~4 MB; two pools per VM pushed `sizeof(VM)` to 8.5 MB, exceeding the 8 MB Linux thread stack and causing a stack-overflow segfault on `AudioEngine engine` construction. Tables moved into a heap-allocated `Storage` struct (one allocation at construction, none in the audio path). `sizeof(StatePool)` 4,243,984 → 48; `sizeof(VM)` 8,886,592 → 398,720.

- **fix: refresh state.output on mid-block cycle wrap in SEQPAT_STEP** (`9cb9504`)
  Spurious trigger pulses on rest cycles after every note (`n"c4 ~ ~ ~"` firing on all four subdivisions). SEQPAT_QUERY refreshes `state.output` only at block start, but 50% of cycle boundaries land mid-block at BPM=120/48kHz. Fix: re-query sequences when SEQPAT_STEP detects a mid-block wrap. Verified by 6 new codegen tests (`[rest_regression]`) and 3 end-to-end VM tests (`[rest_trig]`) counting rising edges across 8 cycles.

- **fix: preserve ExtendedParams<N> slots across hot-swap GC** (`d1ff440`)
  ExtendedParams slots live at `state_id ^ EXT_PARAMS_STATE_XOR` and are only ever accessed via `get_if` (no touch). After a hot-swap the GC swept them, causing all record-options constants (dry/wet, attack/release, damping, etc.) to silently revert to C++ defaults. Fix: in `gc_sweep()`, co-touch each sibling XOR slot for every occupied+touched primary. Affects freeverb, dattorro, pingpong, chorus, flanger, phaser, comb, gate, moog, diode, formant, sallenkey, fold, tape, xfmr, excite, comp, limiter.

- **test: hot-swap regression coverage for ExtendedParams<N>** (`e6c3a3e`)
  535 lines of cedar-level tests covering all 18 ExtendedParams builtins: StatePool unit tests, VM freeverb dry=0/wet=0 repro, parametric dry/wet sweep across 14 builtins, and non-mix slot readback for 4 builtins.

- **feat: add `dur` parameter to euclid()** (`88406a9`)
  `euclid(hits, steps)` previously spanned 1 cycle, making `euclid(3,8)` fire all 8 steps per beat — far too fast. New `dur` parameter (default 4 cycles) matches the classic Strudel/Tidal tresillo at 4/4. Emits a targeted E133 hint when `.fast()`/`.slow()` are incorrectly applied.
