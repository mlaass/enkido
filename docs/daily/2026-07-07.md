## cedar/ — 1 file touched

- **fix(vm): gate hot-swap debug logging behind `CEDAR_VM_SWAP_LOG`** (RT-safety)
  `handle_swap()` runs on the audio thread from `process_block()`; its ten
  `fprintf(stderr, …)` calls allocate and acquire locks, making them
  non-RT-safe and flooding stderr during live-coding swaps. All logging is now
  wrapped in a `CEDAR_VM_SWAP_TRACE` macro compiled out by default; define
  `CEDAR_VM_SWAP_LOG=1` to restore for debugging. Logging-only change — no
  behaviour or audio-path impact.
