## akkado/ — 3 commits, 23 files touched

All three commits are part of an ongoing **parser/codegen hardening** series
(`docs/prd-parser-codegen-hardening.md`), progressing through phases 3, 4, and 5
in the same session.

- **Phase 3 — frozen builtin scope** (`b74107b`)
  Vendors `frozen` 1.2.0 (compile-time perfect-hash library, Apache-2.0) and
  converts `BUILTIN_FUNCTIONS`, `BUILTIN_ALIASES`, and `BUILTIN_VARIABLES` to
  `constexpr frozen::unordered_map`. `SymbolTable` construction no longer inserts
  600+ builtin symbols; a process-shared `builtin_scope()` is consulted as a
  fallback with per-compile `SymbolId` patching. Fixes parallelism blocker
  PB-001. 6 akkado files changed.

- **Phase 4 — Pratt OpInfo table + BinOp family deletion** (`18a3228`)
  Consolidates all four infix-operator parser switches into a single
  `constexpr OPERATORS[]` table and deletes the now-dead `BinOp` AST node
  family end-to-end (`BinOp`, `BinaryOpData`, `NodeType::BinaryOp`, the
  codegen arm, and the `ast_hash` branch). Data-driven parser tests added.
  8 akkado files changed.

- **Phase 5 — shared `lex_primitives` module** (`fae7c86`)
  Extracts `akkado::lex_primitives` (new `hpp` + `cpp`): `CursorBase` (source
  cursor with line/column tracking), character classifiers, `scan_number`,
  `scan_velocity_suffix`, and `pitch_to_midi`. Both `Lexer` and `MiniLexer`
  inherit `CursorBase`, eliminating duplicate nav/classifier code and the
  dual pitch-MIDI semitone tables. Net reduction: −298 LOC across
  `lexer.cpp` (607→490) and `mini_lexer.cpp` (902→721). Also fixes a latent
  column-drift bug after `v"…"` exponent rollback. 9 akkado files changed.
