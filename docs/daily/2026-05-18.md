## akkado/ — 5 commits, ~13 files touched

Also threaded a `closure_allowed` flag through `rewrite_pipes`/`clone_subtree` so the unbound-LHS pipe→closure sugar only fires inside binding contexts; bare undefined identifiers at statement position now emit E005. Regression tests added to `test_akkado.cpp`.

- **feat(effects): unified dry/wet across 32 builtins** *(akkado scope)* — `builtins.hpp` updated for all 32 effects to advertise `dry`/`wet` params; 3 existing test files updated for the new optional param counts.
